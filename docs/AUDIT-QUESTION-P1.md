ส่วนภาพรวมระบบการบริหารจัดการ การผลิต สิ่งที่เคยใช้และถามเสมอ คือ 
•	RM เข้ามาปีนี้ กี่ตัว ตัวไหนที่เข้ามาบ่อยและมากที่สุด
•	RM ที่เข้ามาตอนนี้แต่ละตัวเป็นยังไง ปล่อยผ่านหรือยัง และ ติดอะไร
•	RM ตัวไหนที่ใกล้หมดอายุ ให้ Alert 
•	RM ตัวไหนใกล้หมด ถึง Minimum stock ทีตั้งไว้ ให้ Alert
•	RM ไหนที่ผ่าน ตัวไหนไม่ผ่าน  มีกี่ตัว และจัดการอะไรไปแล้วบ้าง ปิด job หรือยัง
•	ตอนนี้ผลิตอะไรอยู่ กี่ผลิตภัณฑ์
•	ตอนนี้ ผลิตภัณฑ์อะไรบ้างที่อยู่ในระหว่าง QC รอ Release และ กำลังวิเคราะห์เรื่องอะไร ทำไมถึงยังปล่อยไม่ได้
•	FG ใดที่ผ่านแล้วบ้าง 

Inventory
•	รายละเอียดด้านล่างที่แสดง น่าจะต้องแยกตากชนิด คือ Raw material/ Packing  material / Finished goods
•	รายละเอียดของแต่ละหมวด ควร มี วันที่รับเข้า / คนรับเข้า / คนตรวจสอบ /จำนวนรับเข้า บอก pack size + จำนวน / ผู้ผลิต / ผู้ขาย / ผู้นำเข้า / รุ่นผลิต / วันผลิต / วันหมดอายุ /  Retest date /  สินค้าคงเหลือ / มีใบเอกสารอะไรมาให้บ้าง COA/ Spec/ MSDS จากผู้ผลิต
•	ส่วนของสารสกัด อาจต้องมีเพิ่มส่วนว่า  ชื่อวิทยาศาสตร์ เพราะว่า พืชเดียวกันคล้ายๆกัน อาจมีชื่อวิทยาศาสตร์ไม่เหมือนกัน อันนี้ จะให้ดูตรงนี้ได้เลย หรือ ให้ไปเปิด COA เอาเอง (ส่วนตัว คิดว่าดูตรงนี้ดีกว่า เร็วดี) / สกัดด้วยอะไร / ส่วนที่ใช้ /  อันนี้อาจละเอียดไป แต่ให้เป็นไอเดียค่ะ
•	ส่วน Finished goods อาจจะต้องเพิ่มช่อง strength เพราะว่ายาบางตัว ไม่ได้มีความแรงเดียว จะได้ดูง่ายค่ะ ถ้าไปเขียนรวมกับชื่อ คิดว่า อาจจะหายาก
•	ส่วนพืช สมุนไพร ถ้ามีรูปภาพด้วยจะดีมากค่ะ 
•	สถานะ ถ้าติด QC น่าจะมีบอกว่า ติดที่หัวข้อใด ยังไง
•	Inventory มีแบ่งเป็น Expire alert อีกหัวข้อ คิดว่า ดี แต่จะทำยังไง ให้รู้เลย ตั้งแต่ใช่ Tab items
•	Inventory of packaging ต้องมีรุปถ่าย เนื่องจากว่า ขวด อาจสีขาว แต่รูปร่างต่าง ต้องติดสเกลด้วย / ฝา มีหลายแบบ (เกลียว / ฟลิบ / ฉีก) ซิลิก้าเจล ซอง แบบไหน ขนาดเท่าไหร่ / ฟองน้ำเป็นอย่างไร  ....


Production

•	ส่วนนี้  BOM ควรมีช่องให้เติมเลยค่ะ ว่า สารอะไร /จำนวนเท่าไหร่/  Lot อะไรที่ควรหยิบมา/ Batch size เท่าไหร่ / % ในสูตร / ปริมาณที่ต้องชั่ง / ชั่งโดยใคร / ตรวจสอบโดยใคร 
•	จริงๆ BOM มันจะเป็น Formular เลยค่ะ ซึ่งปกติต้อง Link  กับ Master formula ที่โรงงานจัดทำไว้
•	คำว่า Work order น่าจะหมายถึง ขั้นตอนการผลิตมั๊ยคะ ถ้าใช่ อันนี้ก็ต้อง Link  กับ Master formula เช่นกัน จะได้รู้ว่าต้องทำอะไรก่อนหลัง เช่น การทำ line clearance ก่อน หรือ ถ้าจะก่อนๆเลยคือ การตรวจสอบปริมาณวัตถุดิบ วัสดุบรรจุ ทั้งหมดที่จะใช้เลยว่า เพียงพอหรือไม่ ก่อนที่จะวางแผนการผลิต
•	ซึ่งรายละเอียดใน work order ต้องมี กรรมวิธีทั้งหมด เครื่องมือที่ใช้ ห้องที่ใช้ คนทำ คนตรวจสอบ วันที่ เวลาที่ทำ
•	ส่วน Batch record ไม่แน่ใจว่าจะซ้ำกับ Work order หรือไม่  ทีนี้ ปัญหาคือ เวลาเราบันทึก ใน บันทึกการผลิตหรือ Batch record เวลาทำงาน เราต้องเอา Label ที่ถุงสาร มาติดในเอกสาร BMR ด้วยค่ะ เพราะว่าเป็นหลักฐานว่า เราได้ใส่สารตัวนั้นเข้าไปในถังผสมแล้วจริงๆ แล้วมีการเซนชื่อกำกับด้วย  ส่วนเรื่องของ Label หรือ ฉลากผลิตภัณฑ์ ก็ต้องมีการติดใน BMR ด้วย เพื่อยืนยันว่าเราใช้อันนี้ ในการผลิต พร้อมลงชื่อกำกับ 
Quality
•	อาจต้องแยกเป็น RM/ PM/ In-process / Bulk product/ FG
•	Specification + COA ต้องมีทุกอัน
•	ส่วนของ Deviation ดีจังค่ะ ที่มี เพราะว่าเราเอาไปทำ PQR  ได้ สำหรับทุกผลิตภัณฑ์ 
•	ส่วนของ Deviation / CAPA/ Non-conform อยากให้มีรายละเอียดว่า ใคร ทำอะไร เมื่อไหร่ แก้ยังไง ปิดเมื่อไหร่ มีการลงนามรับรองทุกขั้นตอน
