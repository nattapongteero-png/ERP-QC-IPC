**ผู้ทดสอบ:** ฝ่ายบัญชี / QA

## เรื่องนี้คืออะไร (อ่านก่อนทดสอบ)

**ผลต่าง (Variance) = ต้นทุนที่ตั้งไว้ ต่างจากที่ใช้จริงเท่าไหร่**

โรงงานตั้ง "ต้นทุนมาตรฐาน" ไว้ล่วงหน้าว่ายาแคปซูล 1 ขวดควรใช้วัตถุดิบกี่บาท ค่าแรงกี่บาท
พอผลิตจริงเสร็จ ระบบเอา **ของจริง** มาลบ **ที่ตั้งไว้** ผลลัพธ์คือผลต่าง

| ผลต่าง | หมายความว่า |
|---|---|
| ติดลบ (เป็นผลดี) | ใช้จริง**น้อยกว่า**ที่ตั้งไว้ → ประหยัด |
| เป็นบวก (เป็นผลเสีย) | ใช้จริง**มากกว่า**ที่ตั้งไว้ → ต้นทุนบานปลาย |

ผลต่างมี 4 ชนิด:

| ชื่อย่อ | ชื่อไทย | ตอบคำถามว่า |
|---|---|---|
| **MPV** | ผลต่างราคาวัตถุดิบ | ซื้อวัตถุดิบ**แพงหรือถูก**กว่าที่ตั้งไว้ |
| **MUV** | ผลต่างการใช้วัตถุดิบ | **ใช้วัตถุดิบเปลือง**หรือประหยัดกว่าที่ตั้งไว้ |
| **LRV** | ผลต่างอัตราค่าแรง | จ่ายค่าแรง**ต่อชั่วโมง**แพงหรือถูกกว่าที่ตั้งไว้ |
| **LEV** | ผลต่างประสิทธิภาพค่าแรง | ทำงาน**เร็วหรือช้า**กว่าเวลาที่ตั้งไว้ |

## ปัญหาเดิมที่แก้ไปแล้ว (สิ่งที่ต้องยืนยัน)

| # | อาการที่ผู้ใช้เคยเจอ | สาเหตุ |
|---|---|---|
| 1 | ผลต่างวัตถุดิบขึ้น **0 ทุกรายการ** ทั้งที่เบิกของจริงไม่เท่าแผน | ระบบไม่ได้ดูของที่เบิกจริง ใช้ตัวเลขแผนมาลบตัวเอง = 0 เสมอ |
| 2 | ผลต่างค่าแรงขึ้น **0 ทุกรายการ** ทั้งที่ใช้เวลาจริงไม่เท่าแผน | ระบบไม่ได้ดูเวลาทำงานจริงที่บันทึกไว้ |
| 3 | **เลือกช่วงวันที่แล้วไม่มีอะไรเปลี่ยน** ข้อมูลเท่าเดิม | ระบบรับค่าวันที่มา แต่ไม่ได้เอาไปกรองจริง |
| 4 | **กดคำนวณผลต่างแล้ว error / ไม่มีข้อมูลขึ้นเลย** | รูปแบบวันที่ผิด ฐานข้อมูลปฏิเสธการบันทึกทุกครั้ง |

> ⚠️ ข้อ 4 ร้ายแรงที่สุด — ทำให้**ไม่เคยมีข้อมูลผลต่างในระบบเลยแม้แต่รายการเดียว**
> ถ้าทดสอบแล้วยังเจอข้อนี้ ให้หยุดและแจ้งทันที ข้ออื่นจะทดสอบไม่ได้เลย

## เตรียมก่อนทดสอบ

ต้องมีใบสั่งผลิตที่ **ผลิตเสร็จแล้ว** และมีข้อมูลครบ 3 อย่าง:

1. **จำนวนผลิตจริง** มากกว่า 0
2. **รายการเบิกวัตถุดิบ** พร้อม **ราคาต่อหน่วย** (สำคัญ — ถ้าไม่มีราคา ผลต่างวัตถุดิบจะเป็น 0 ซึ่ง**ถูกต้อง** ไม่ใช่บั๊ก)
3. **บันทึกเวลาทำงาน** (ชั่วโมงจริง) ในขั้นตอนการผลิต
4. สินค้าตัวนั้นต้องมี **ต้นทุนมาตรฐาน** อยู่แล้ว (เมนู บัญชี → ต้นทุนมาตรฐาน)

> 📌 บนระบบทดสอบตอนนี้ ใบสั่งผลิต **WO2606106047** ผลิตเสร็จ 500 หน่วย มีรายการเบิก 6 รายการ
> แต่ **ยังไม่ได้ใส่ราคาต่อหน่วย** ผลต่างวัตถุดิบจึงออกมาเป็นค่าเต็มจำนวนของมาตรฐาน
> ถ้าจะทดสอบให้เห็นภาพจริง ควรใส่ราคาต่อหน่วยในรายการเบิกก่อน

### TC-02 — ผลต่างวัตถุดิบต้องไม่เป็น 0 (ข้อ 1)

| ขั้น | ทำอะไร | ต้องเห็นอะไร |
|---|---|---|
| 1 | เลือกใบสั่งผลิตที่**เบิกวัตถุดิบจริงไม่เท่ากับแผน** และมีราคาต่อหน่วย | |
| 2 | คำนวณผลต่าง แล้วดูแท็บ **ผลต่างวัตถุดิบ** | เห็น **MPV** และ **MUV** |
| 3 | ดูตัวเลขในคอลัมน์ผลต่าง | **ไม่ใช่ 0.00** |

**วิธีตรวจว่าถูกต้องจริง (ไม่ใช่แค่มีตัวเลข):**

```
ผลต่าง = (ของจริง) − (มาตรฐาน)
```
เช่น มาตรฐานวัตถุดิบ 80 บาท/หน่วย ผลิต 500 หน่วย → มาตรฐาน = 40,000 บาท
ถ้าเบิกจริงรวม 42,000 บาท → ผลต่าง = **+2,000 (เป็นผลเสีย)**

**ผ่านเมื่อ:** ตัวเลขไม่เป็น 0 และคำนวณมือแล้วตรง
**ไม่ผ่านเมื่อ:** เป็น 0.00 ทั้งที่เบิกจริง≠แผน หรือตัวเลขไม่ตรงกับที่คำนวณมือ

---

### TC-03 — ผลต่างค่าแรงต้องไม่เป็น 0 (ข้อ 2)

| ขั้น | ทำอะไร | ต้องเห็นอะไร |
|---|---|---|
| 1 | เลือกใบสั่งผลิตที่**บันทึกชั่วโมงทำงานจริง**ไว้ และไม่เท่ากับแผน | |
| 2 | คำนวณผลต่าง แล้วดูแท็บ **ผลต่างค่าแรง** | เห็น **LRV** และ **LEV** |
| 3 | ดูตัวเลข | **ไม่ใช่ 0.00** |

**ตรวจ LEV (ประสิทธิภาพ):**
```
LEV = (ชั่วโมงจริง − ชั่วโมงมาตรฐาน) × อัตราค่าแรงมาตรฐาน
```
เช่น มาตรฐาน 40 ชม. ทำจริง 45 ชม. อัตรา 360 บาท/ชม.
→ LEV = (45−40) × 360 = **+1,800 (เป็นผลเสีย — ทำงานช้ากว่าแผน)**

**ผ่านเมื่อ:** ไม่เป็น 0 และคำนวณมือแล้วตรง

### TC-04 — ตัวกรองวันที่ต้องใช้งานได้จริง (ข้อ 3)

**นี่คือข้อที่พลาดง่ายที่สุด** เพราะเดิม "ดูเหมือนทำงาน" — กดแล้วหน้าจอรีเฟรช แต่ข้อมูลเท่าเดิม

| ขั้น | ทำอะไร | ต้องเห็นอะไร |
|---|---|---|
| 1 | ไม่ใส่ตัวกรอง **จดจำนวนรายการทั้งหมด** | เช่น 12 รายการ |
| 2 | ใส่ **ตั้งแต่วันที่** และ **ถึงวันที่** เป็นช่วงในอดีตไกล ๆ (เช่น 1/1/2000 – 2/1/2000) | **ต้องไม่มีข้อมูลเลย (0 รายการ)** |
| 3 | เปลี่ยนเป็นช่วงกว้างครอบวันนี้ (เช่น 1/1/2020 – วันนี้) | **กลับมาเห็นข้อมูลเท่าขั้นที่ 1** |
| 4 | ใส่เฉพาะ **วันนี้** ทั้งจากและถึง | เห็นเฉพาะรายการที่คำนวณวันนี้ |

**ผ่านเมื่อ:** จำนวนรายการ**เปลี่ยนตามช่วงวันที่**
**ไม่ผ่านเมื่อ:** ใส่ช่วงปี 2000 แล้ว**ยังเห็นข้อมูลเท่าเดิม** = ตัวกรองถูกทิ้ง (บั๊กเดิมกลับมา)

## ⚠️ จุดที่เข้าใจผิดกันบ่อย

**"ผลต่างเป็น 0 = บั๊ก" — ไม่เสมอไป**

ผลต่างเป็น 0 **ถูกต้อง** ในกรณีเหล่านี้:
- ใบสั่งผลิตนั้นยังไม่ได้บันทึกการเบิกจริง (ระบบใช้ค่ามาตรฐานแทน)
- รายการเบิกไม่มีราคาต่อหน่วย (คิดเป็นเงินไม่ได้)
- ใช้จริงเท่ากับแผนพอดีจริง ๆ

**ก่อนแจ้งบั๊กว่า "ผลต่างเป็น 0" กรุณาตรวจก่อนว่าใบสั่งผลิตนั้นมีข้อมูลจริงครบ**
มิฉะนั้นจะเป็นการแจ้งผิด และทีมพัฒนาต้องเสียเวลาไล่ตาม
