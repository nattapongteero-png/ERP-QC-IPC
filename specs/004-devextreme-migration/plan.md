# Implementation Plan: DevExtreme UI Migration

**Branch**: `004-devextreme-migration` | **Date**: 2025-12-19 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/004-devextreme-migration/spec.md`

## Summary

Migrate all 30 existing UI components from custom Radix UI/Tailwind-based implementation to DevExtreme by DevExpress. This enables enterprise-grade features including advanced data grids with sorting/filtering/export, rich form controls with validation, and consistent theming. The migration maintains existing functionality while leveraging DevExtreme's React 19 and Next.js 15 compatibility.

## Technical Context

**Language/Version**: TypeScript 5.x with React 19, Next.js 15 (App Router)
**Primary Dependencies**: DevExtreme React 25.1.x, devextreme-themebuilder 25.1.x, Zod 4.2.x (existing)
**Storage**: N/A (no database changes - UI-only migration)
**Testing**: Vitest for unit tests, Playwright for E2E (existing)
**Target Platform**: Web (desktop, tablet, mobile responsive)
**Project Type**: Web application (Next.js App Router)
**Performance Goals**: Page load < 3 seconds, API response < 500ms, table operations < 500ms for 1000 rows
**Constraints**: Bundle size increase must be justified, maintain WCAG 2.1 AA accessibility
**Scale/Scope**: 30 components, 11 pages, 6 component categories

## Migration Phases

### Phase 1: Foundation Setup

1. Install DevExtreme dependencies
2. Configure emerald theme with ThemeBuilder
3. Create DevExtreme provider with Thai locale
4. Create Zod-DevExtreme validation adapter
5. Update globals.css with theme import
6. Verify build and lint pass

### Phase 2: Core Components (P1 Priority)

1. Migrate Table → DataGrid (data-grid.tsx)
2. Migrate Input → TextBox (input.tsx)
3. Migrate Select → SelectBox (select.tsx)
4. Migrate DatePicker → DateBox (date-picker.tsx)
5. Migrate Button → Button (button.tsx)
6. Update item and warehouse pages to use new components

### Phase 3: Dialog & Form Components (P2 Priority)

1. Migrate Dialog → Popup (dialog.tsx)
2. Migrate ItemSearchDialog → DevExtreme Popup with DataGrid
3. Migrate CustomerSearchDialog → DevExtreme Popup with DataGrid
4. Migrate ItemEditForm → DevExtreme Form
5. Migrate WarehouseEditForm → DevExtreme Form
6. Create form-field wrapper for consistent validation display

### Phase 4: Supporting Components (P3 Priority)

1. Migrate DropdownMenu → DevExtreme ContextMenu/DropDownButton
2. Migrate Tabs → DevExtreme TabPanel
3. Migrate Tooltip → DevExtreme Tooltip
4. Update Card, KPI Card, Stat Card with consistent styling
5. Update Empty State, Skeleton components
6. Migrate Badge with DevExtreme styling patterns

### Phase 5: Integration & Testing

1. Run full E2E test suite
2. Performance audit (Lighthouse, bundle analysis)
3. Accessibility audit (axe-core)
4. Visual regression testing
5. Fix any remaining issues
6. Update component documentation
