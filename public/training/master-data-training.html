MODULE 1 · วัตถุดิบ 05 / 36

วัตถุดิบ (Raw Materials)

Inventory → Items → วัตถุดิบ → + สร้างใหม่
  1. เข้าเมนู Inventory > Items
  2. เลือกแถบ "วัตถุดิบ" (Raw Materials)
  3. คลิกปุ่ม "+ สร้างรายการใหม่"
  4. กรอกข้อมูล: รหัส, ชื่อไทย, ชื่ออังกฤษ, หมวดหมู่, หน่วยหลัก
  5. กด "บันทึก"
ฟิลด์จำเป็นคำอธิบาย
รหัสวัตถุดิบ (Code)จำเป็นระบบสร้างอัตโนมัติ เช่น RM-0001
ชื่อ (ไทย)จำเป็นชื่อสมุนไพร เช่น ขมิ้นชัน
ชื่อ (อังกฤษ)จำเป็นเช่น Turmeric
หมวดหมู่ (Category)จำเป็นสมุนไพรสด / แห้ง / สารเสริม
หน่วยหลัก (Primary Unit)จำเป็นkg / g / l / ml
หน่วยรอง (Secondary Unit)ทางเลือกหน่วยแปลง
★เคล็ดลับ
ระบบสร้างรหัสอัตโนมัติ (Auto-code) RM-XXXX สำหรับวัตถุดิบ
MODULE 1 · บรรจุภัณฑ์ 06 / 36

บรรจุภัณฑ์ (Packaging)

Inventory → Items → บรรจุภัณฑ์ → + สร้างใหม่
  1. เข้าเมนู Inventory > Items
  2. เลือกแถบ "บรรจุภัณฑ์" (Packaging)
  3. คลิก "+ สร้างรายการใหม่"
  4. กรอกข้อมูล: รหัส, ชื่อ, ประเภทบรรจุภัณฑ์, หน่วย
  5. กด "บันทึก"
ฟิลด์จำเป็นคำอธิบาย
รหัสบรรจุภัณฑ์ (Code)จำเป็นAuto: PK-XXXX
ชื่อบรรจุภัณฑ์จำเป็นเช่น ขวด PET 100 ml
ประเภท (Type)จำเป็นขวด / กล่อง / ซอง / ฉลาก
หน่วยนับจำเป็นชิ้น / ใบ / ม้วน
★เคล็ดลับ
บรรจุภัณฑ์รวมถึงวัสดุสิ้นเปลือง เช่น ฉลาก, กล่องชั้นนอก, seal
MODULE 1 · สินค้าสำเร็จรูป 07 / 36

สินค้าสำเร็จรูป (Finished Goods)

Inventory → Items → สินค้าสำเร็จรูป → + สร้างใหม่
  1. เข้าเมนู Inventory > Items
  2. เลือกแถบ "สินค้าสำเร็จรูป" (Finished Goods)
  3. คลิก "+ สร้างรายการใหม่"
  4. กรอกข้อมูล: รหัส, ชื่อผลิตภัณฑ์, รูปแบบยา, ขนาด, หน่วย
  5. กด "บันทึก"

รหัสสินค้า (Code)จำเป็นAuto: FG-XXXX
ชื่อผลิตภัณฑ์ (ไทย)จำเป็นเช่น แคปซูลขมิ้นชัน 500 มก.
ชื่อผลิตภัณฑ์ (อังกฤษ)จำเป็น

MODULE 2 · ใบสั่งซื้อ 11 / 36

ใบสั่งซื้อ (Purchase Order)

Purchasing → Orders → + สร้างใบสั่งซื้อ
  1. เข้าเมนู Purchasing > Orders
  2. คลิก "+ สร้างใบสั่งซื้อใหม่"
  3. เลือก Supplier
  4. เพิ่มรายการวัตถุดิบ: Item + จำนวน + ราคาต่อหน่วย
  5. ตรวจสอบยอดรวม
  6. กด "บันทึก" → สถานะ Draft
  7. กด "ส่งอนุมัติ" → สถานะ Pending Approval
ฟิลด์จำเป็นคำอธิบาย
เลข POจำเป็นAuto: PO2026-XXXX
Supplierจำเป็นเลือกจากรายการ
วันที่สั่งซื้อจำเป็น
วันที่ต้องการทางเลือกExpected delivery
รายการสินค้าจำเป็นItem + Qty + Price
★เคล็ดลับ
PO ต้องได้รับอนุมัติก่อนจึงจะรับเข้าสินค้าได้
MODULE 2 · บันทึกรับเข้า 12 / 36

บันทึกรับเข้า (Goods Receipt)

Purchasing → Orders → เลือก PO → Receive
  1. เข้าเมนู Purchasing > Orders
  2. เลือก PO ที่สถานะ "Approved"
  3. คลิกปุ่ม "Receive" (รับเข้า)
  4. ระบุ: จำนวนที่รับจริง, เลข Lot/Batch จาก Supplier
  5. เลือกคลังที่จะรับเข้า (Warehouse)
  6. ยืนยันรับเข้า
  7. ระบบสร้าง Lot อัตโนมัติ → สถานะ "Quarantine"
!ข้อควรระวัง
สินค้าที่รับเข้าจะถูก กักกัน (Quarantine) อัตโนมัติ — ต้องผ่าน QC ก่อนนำไปใช้ผลิต
MODULE 2 · Lot & QC 13 / 36

Lot & QC Pass

Quality → Tests → + สร้าง QC Test
  1. เข้าเมนู Quality > Tests
  2. คลิก "+ สร้าง QC Test ใหม่"
  3. เลือก Lot ที่ต้องการตรวจ (สถานะ Quarantine)
  4. ระบุผลตรวจตาม Specification
  5. กด "บันทึกผลตรวจ"
  6. ถ้า ผ่าน → กด "Release" → Lot เปลี่ยนเป็น "Released" (พร้อมใช้)
  7. ถ้า ไม่ผ่าน → กด "Reject" → Lot เปลี่ยนเป็น "Rejected"
✓สำคัญ
Lot ที่ Released แล้วเท่านั้นที่จะดึงไปใช้ในกระบวนการผลิตได้

ใบสั่งผลิต (Work Order)

  2. คลิก "+ สร้างใบสั่งผลิตใหม่"

  5. กำหนดวันเริ่ม-สิ้นสุด

MODULE 3 · ตัดจ่ายวัตถุดิบ 17 / 36

การตัดจ่ายวัตถุดิบ (Material Issue)

Production → Work Orders → [WO] → Material Weighing
  1. เปิด Work Order ที่สถานะ "In Progress"
  2. ไปที่แถบ "Material Weighing" (การชั่งวัตถุดิบ)
  3. ระบบแสดงรายการวัตถุดิบจาก BOM
  4. เลือก Lot ที่ต้องการใช้ (เฉพาะ Released)
  5. กรอกน้ำหนักที่ชั่งจริง
  6. ผู้ชั่งบันทึก → ผู้ตรวจสอบ (Verifier) ยืนยัน
  7. ระบบตัดสต็อกจาก Lot ที่เลือกอัตโนมัติ
!Dual Control
ผู้ชั่ง (Operator) และผู้ตรวจสอบ (Verifier) ต้องเป็นคนละคน
iFEFO
ระบบตัดจ่ายตาม FEFO — First Expired, First Out อัตโนมัติ
MODULE 3 · บันทึกการผลิต 18 / 36

บันทึกขั้นตอนการผลิต

Production → Work Orders → [WO] → SOP Execution / IPC
  1. เปิด Work Order ที่กำลังผลิต
  2. ไปที่แถบ "SOP Execution" — ทำเครื่องหมายขั้นตอนที่ทำเสร็จ
  3. ไปที่แถบ "IPC" — บันทึกค่าตรวจระหว่างผลิต (In-Process Control)
  4. ไปที่แถบ "Environmental Monitoring" — ดูอุณหภูมิ/ความชื้น
  5. บันทึกปริมาณผลผลิต (Actual Output)
  6. บันทึกของเสีย (Waste/Reject) ถ้ามี
iIPC คืออะไร?
IPC บันทึกค่าเช่น ความแข็งเม็ดยา, น้ำหนักเม็ด, ความชื้น — เทียบกับ Spec อัตโนมัติ

MODULE 4 · รับ FG 21 / 36

รับสินค้าสำเร็จรูป (FG Receipt)

Inventory → Lots → + สร้าง Lot ใหม่
  1. Work Order ผลิตเสร็จ — สถานะ "Completed"
  2. เข้าเมนู Inventory > Lots
  3. สร้าง Lot ใหม่ สำหรับ FG
  4. ระบุ: สินค้า, จำนวนที่รับ, คลังปลายทาง
  5. Lot สร้างขึ้นสถานะ "Quarantine" อัตโนมัติ
  6. รอ Final QC ก่อน Release
MODULE 4 · Final QC 22 / 36

Final QC & Release

Quality → Tests → + สร้าง QC Test → Release
  1. เข้าเมนู Quality > Tests
  2. สร้าง QC Test สำหรับ FG Lot
  3. ตรวจสอบตาม Specification (physical, chemical, micro)
  4. ถ้า ผ่าน → กด Release → Lot พร้อมขาย
  5. ถ้า ไม่ผ่าน → กด Reject → แยกเก็บ/ทำลาย
iสำคัญ
FG ที่ Release แล้ว จะเข้าสู่คลังสินค้าพร้อมขาย (Available for Sale)

MODULE 6 · QC Test 29 / 36

การทดสอบ (QC Test)

Quality → Tests → + สร้าง QC Test ใหม่
  1. เข้าเมนู Quality > Tests
  2. คลิก "+ สร้าง QC Test ใหม่"
  3. เลือก Lot ที่ต้องการตรวจ (สถานะ Quarantine)
  4. เลือกประเภท: Incoming / In-Process / Final
  5. บันทึกผลตรวจตาม Specification
  6. กด "บันทึก" → ระบบเทียบผลกับ Spec อัตโนมัติ
ฟิลด์จำเป็นคำอธิบาย
Test Nameจำเป็นชื่อการทดสอบ (เลือกจาก IPC Criteria)
Typeจำเป็นIncoming / In-Process / Final
Lotจำเป็นเลือก Lot ที่ต้องการตรวจ
Resultจำเป็นค่าผลตรวจ (ตัวเลข/ข้อความ)
StatusAutoPass / Fail (เทียบกับ Spec)
★เคล็ดลับ
ระบบเทียบผลตรวจกับ Specification อัตโนมัติ — ถ้าไม่ผ่าน สถานะจะเป็น Fail ทันที
MODULE 6 · Specification 30 / 36

ข้อกำหนดการทดสอบ (Specification)

Quality → Specifications → + สร้างข้อกำหนดใหม่
  1. เข้าเมนู Quality > Specifications
  2. คลิก "+ สร้างข้อกำหนดใหม่"
  3. เลือก Item (วัตถุดิบ/FG)
  4. ระบุ Test Name, Min-Max Range, Unit
  5. กำหนด Critical / Non-Critical
  6. กด "บันทึก"
ฟิลด์จำเป็นคำอธิบาย
Itemจำเป็นเลือกสินค้าที่ต้องกำหนด Spec
Test Nameจำเป็นเช่น Moisture, Hardness
Min Valueจำเป็นค่าต่ำสุดที่ยอมรับ
Max Valueจำเป็นค่าสูงสุดที่ยอมรับ
Unitจำเป็นหน่วย เช่น %, mg, CFU
Is Criticalทางเลือกระบุเป็น Critical Parameter
★เคล็ดลับ
Spec ที่กำหนดเป็น Critical จะถูกเน้นในรายงาน QC — ห้ามปล่อยผ่านถ้า Critical ไม่ผ่าน
MODULE 6 · Deviation 31 / 36

ความเบี่ยงเบน (Deviation)

Quality → Deviations → + รายงาน Deviation ใหม่
  1. เข้าเมนู Quality > Deviations
  2. คลิก "+ รายงาน Deviation ใหม่"
  3. กรอก: หัวข้อ, แหล่งที่มา (Production/Quality/Warehouse)
  4. ระบุระดับความรุนแรง: Minor / Major / Critical
  5. บันทึก Root Cause Analysis
  6. กำหนด Corrective Action + Preventive Action
  7. กด "บันทึก" → สถานะ Open
ฟิลด์จำเป็นคำอธิบาย
Deviation No.Autoระบบสร้างอัตโนมัติ
Titleจำเป็นหัวข้อความเบี่ยงเบน
Sourceจำเป็นProduction / Quality / Warehouse
Severityจำเป็นMinor / Major / Critical
Root Causeจำเป็นสาเหตุที่แท้จริง
CAPAทางเลือกการแก้ไข + ป้องกัน
!ข้อควรระวัง
Deviation ระดับ Critical ต้องได้รับการแก้ไขภายใน 24 ชม. ตามข้อกำหนด GMP

MODULE 7 · Role 33 / 36

การจัดการ Role (สิทธิการใช้งาน)

HR → Roles → + สร้าง Role ใหม่
  1. เข้าเมนู HR > Roles
  2. คลิก "+ สร้าง Role ใหม่"
  3. กรอก: Code, ชื่อ Role, คำอธิบาย
  4. เลือก Permissions ที่ต้องการ
  5. กด "บันทึก"
  6. Role ที่สร้างจะแสดงในรายการพร้อมจำนวน Permission
ฟิลด์จำเป็นคำอธิบาย
Codeจำเป็นรหัส Role เช่น PROD_OPERATOR
Nameจำเป็นชื่อ เช่น Production Operator
Descriptionทางเลือกคำอธิบาย
Permissionsจำเป็นสิทธิการเข้าถึงแต่ละเมนู
StatusAutoActive / Inactive
iหมายเหตุ
Role ประเภท System (สีม่วง) ไม่สามารถแก้ไขหรือลบได้ — เป็น Role พื้นฐานของระบบ
MODULE 7 · User 34 / 36

การจัดการผู้ใช้งาน (User Management)

Users → + เพิ่มผู้ใช้งานใหม่
  1. เข้าเมนู Users (จาก sidebar)
  2. คลิก "+ เพิ่มผู้ใช้งานใหม่"
  3. กรอก: ชื่อ, Email, Password
  4. เลือก Role (จาก HR Roles)
  5. เลือก Department
  6. กด "บันทึก"
  7. ผู้ใช้สามารถ login ได้ทันที
ฟิลด์จำเป็นคำอธิบาย
Nameจำเป็นชื่อผู้ใช้งาน
Emailจำเป็นใช้เป็น username สำหรับ login
Passwordจำเป็นกำหนดรหัสผ่านเริ่มต้น
Roleจำเป็นเลือกจาก HR Roles
Departmentทางเลือกแผนกที่สังกัด
StatusAutoActive / Inactive
!ข้อควรระวัง
ทุกการเปลี่ยนแปลงถูกบันทึกใน Audit Log — ห้ามแชร์ Password กับผู้อื่น
