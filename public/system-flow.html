Dashboard

แดชบอร์ดภาพรวม
  • KPI สรุปภาพรวมทั้งระบบ
  • แจ้งเตือนสำคัญ
  • สรุปยอดผลิต/ขาย/ซื้อ

Inventory (คลังสินค้า)

บริหารจัดการวัตถุดิบ สินค้า และ Lot
  • รายการสินค้า (Items)
  • Lot Management
  • คลังสินค้า (Warehouses)
  • รายการเคลื่อนไหว (Transactions)
  • แจ้งเตือนหมดอายุ (Expiry Alerts)
  • ใบเบิกวัตถุดิบ (Requisitions)

Production (การผลิต)

วางแผนและควบคุมการผลิต
  • สูตรการผลิต (BOM/Recipes)
  • ใบสั่งผลิต (Work Orders)
  • บันทึกการผลิต eBMR
  • ชั่งวัตถุดิบ (Material Weighing)
  • ขั้นตอน SOP Execution
  • บันทึกสภาพแวดล้อม
  • ตรวจสอบสินค้าสำเร็จรูป
  • Master Data (ห้อง, อุปกรณ์, IPC)

Quality (คุณภาพ)

ทดสอบและควบคุมคุณภาพ
  • ผลทดสอบ (QC Tests)
  • ข้อกำหนด (Specifications)
  • การเบี่ยงเบน (Deviations)
  • QC Disposition (ปล่อยผ่าน/ปฏิเสธ)

GMP Compliance

ระบบ GMP และเอกสารคุณภาพ
  • เอกสาร (Document Control)
  • การเปลี่ยนแปลง (Change Control)
  • CAPA
  • ข้อร้องเรียน (Complaints)
  • เรียกคืน (Recalls)
  • สุขาภิบาล (Sanitation)
  • ความคงตัว (Stability)
  • ตรวจสอบภายใน (Internal Audit)
  • สัญญา (Contracts)
  • PQR (Product Quality Review)

Purchasing (จัดซื้อ)

จัดซื้อจัดจ้างวัตถุดิบ
  • ใบขอซื้อ (Purchase Requisitions)
  • ใบสั่งซื้อ (Purchase Orders)
  • ผู้ขาย (Vendors)
  • รับสินค้า (Goods Receiving)

Sales (ขาย)

บริหารการขายและลูกค้า
  • ใบสั่งขาย (Sales Orders)
  • VMI Orders
  • ลูกค้า (Customers)

Accounting (บัญชี)

ระบบบัญชีคู่ ภาษี VAT/WHT
  • ผังบัญชี (Chart of Accounts)
  • ประเภทบัญชี (Account Types)
  • สมุดรายวัน (Journal Entries)
  • เจ้าหนี้ AP (Invoices, Aging, Payments)
  • ลูกหนี้ AR (Invoices, Aging, Receipts)
  • สินทรัพย์ถาวร / อุปกรณ์
  • กระทบยอดธนาคาร
  • ใบลดหนี้/ใบเพิ่มหนี้
  • 3-Way Matching
  • ปิดงวด / อนุมัติ
  • รายงาน (Trial Balance, งบการเงิน, VAT, WHT)

Cost Management (ต้นทุน)

วิเคราะห์และบริหารต้นทุน
  • Dashboard ต้นทุน
  • ต้นทุนเพิ่มเติม (Landed Costs)
  • ศูนย์ต้นทุน (Work Centers)
  • สรุปต้นทุน (Cost Summary)
  • ต้นทุนมาตรฐาน / ผลต่าง

VMI Portal

Vendor Managed Inventory
  • VMI Dashboard
  • Sync ข้อมูล
  • VMI Orders
  • Webhook Integration

HR (ทรัพยากรบุคคล)

บริหารบุคลากรและสิทธิ์
  • โครงสร้างองค์กร
  • พนักงาน / ตำแหน่ง
  • ฝึกอบรม (Training)
  • มอบอำนาจ (Authorizations)
  • สุขภาพ (Health Records)
  • บทบาท / สิทธิ์
  • Audit Trail

Issues (ปัญหา/แจ้งซ่อม)

ระบบแจ้งปัญหาและติดตาม
  • Dashboard
  • รายการปัญหาทั้งหมด
  • แจ้งปัญหาใหม่

Admin & Settings

ตั้งค่าระบบและสิทธิ์
  • จัดการผู้ใช้ (Users)
  • Confidential Groups
  • Approval Workflows
  • Matching Tolerances
  • Reports / Reporting

BOM → Work Order → Material Requisition → Weighing → eBMR → IPC/QC → FG Receipt → Cost Calc

Production Inventory Quality Cost

Sales Order → Stock Check → Pick/Pack → Delivery → AR Invoice → AR Receipt

Sales Inventory Accounting

VMI Sync → Auto Order → Webhook → Sales Order → Fulfillment

SOP Document → BOM Steps → eBMR Execution → Deviation → CAPA → Change Control

GMP Production Quality

6. HR → ทุกโมดูล (สิทธิ์ & Audit)

User Roles → Permission Check → Authorization Matrix → Audit Trail → Electronic Signature

HR Production Quality Accounting GMP

Unit Cost → Standard Cost → Variance Analysis → Journal Entry → Financial Reports
