📋 รายละเอียดแต่ละสถานะ

⏰
1. Pending
รอเริ่ม — สีเทา · icon นาฬิกา

ข้อความที่แสดง: Pending ป้ายสีเทา

Operator ทำอะไร:

  • กดปุ่ม ▶ Start
  • ระบบเปิด dialog ยืนยัน → กด "Start Step"

เงื่อนไขที่ Start ได้:

  • Step ก่อนหน้าต้อง Completed (หรือ Verified ถ้า require verification)
  • ถ้ายังไม่พร้อม → จะเห็นป้ายสีเหลือง รอตรวจสอบ Step X ก่อน

➡ หลังกด Start → เปลี่ยนเป็น In Progress

▶
2. In Progress
กำลังทำ — สีน้ำเงิน · card มี border + bg น้ำเงิน

ข้อความที่แสดง: ป้ายสีน้ำเงิน In Progress + card highlight สีฟ้า

Operator ทำอะไร:

  • ทำงานตามขั้นตอนใน BOM Instructions
  • ติ๊ก checklist Sub-Steps ครบทุกข้อ (ถ้ามี) — ปุ่ม "ทำเครื่องหมายทั้งหมด" ก็ได้
  • กดปุ่ม ✓ Complete

Dialog "Complete Production Step" ขึ้นมา ต้องกรอก:

  • Actual Parameters — ค่าจริงที่ทำได้ เช่น
    • Temperature: 250 (expected: 240)
    • Time: 30 (expected: 30)
    • Pressure: 5 (expected: 5)
  • Notes — สังเกตการณ์ / ข้อสังเกตเพิ่มเติม

➡ กด "Complete Step" → เปลี่ยนเป็น Completed

✓
3. Completed
ทำเสร็จแล้ว — สีเขียว · icon ✓

ข้อความที่แสดง: Completed ป้ายสีเขียว

ขั้นตอนต่อไป:

  • ถ้า step ไม่ Requires Verification → จบขั้นนี้ ไปทำ step ถัดไปได้
  • ถ้า step Requires Verification → ต้องมีคนอื่นมา Verify
⚠ Dual-Control: คน Verify ต้องไม่ใช่คน Operator
  • ถ้าคุณคือคน Operator ของ step นี้ → ปุ่ม Verify ไม่แสดง
  • จะเห็น ⏳ Awaiting other verifier แทน
  • ต้องให้ user อื่น (Supervisor / QC) login เข้ามากด Verify

คนอื่นกดปุ่ม 👤 Verify → เปลี่ยนเป็น Verified

👤
4. Verified
ตรวจสอบรับรองแล้ว — สีฟ้า · icon 👤

ข้อความที่แสดง: ป้ายสีฟ้า Verified

ผลที่ตามมา:

  • จบขั้นตอนนี้ — สามารถไปทำ step ถัดไปได้
  • ป้ายสีม่วง Requires Verification หาย
  • Progress bar ของ work order เคลื่อนไปข้างหน้า

นี่คือสถานะ "สมบูรณ์" — ตามมาตรฐาน GMP

🛡 GMP Dual-Control Rule

มาตรฐาน GMP กำหนดว่า "คนที่ทำ ≠ คนที่ตรวจสอบ" เพื่อให้มี independent check

สถานการณ์ปุ่ม Verifyป้ายที่แสดง
คุณเป็น operator ของ step นี้ ❌ ไม่แสดง ⏳ Awaiting other verifier
คุณเป็น user คนอื่น (เช่น Supervisor) ✅ แสดง 👤 Verify
Step ไม่ require verification — ไม่ต้อง Verify, จบที่ Completed
💡 หมายเหตุ: เมื่อมี user อื่นกด Verify จาก browser อื่น — หน้าของคุณจะ refresh สถานะอัตโนมัติภายใน ~1 วินาที (ไม่ต้องกด refresh manual)

🎬 ตัวอย่าง Flow จริง

Step 1: ผสมผง (requires verification)
Operator A login → กด Start Pending → In Progress
Operator A ทำงาน → ติ๊ก sub-steps ครบ → กด Complete
กรอก: Temp=25°C, Time=15min, Notes="ผงผสมเรียบร้อย" In Progress → Completed
→ ปุ่ม Verify ไม่แสดงให้ A (เป็น operator)
Supervisor B login → เห็นปุ่ม Verify → กด Completed → Verified ✓
Step 2: Granulation (เริ่มได้ตอนนี้)
ขณะ Step 1 ยัง Completed (ยังไม่ Verified)
Step 2 จะติด รอตรวจสอบ Step 1 ก่อน

🏷 ป้ายเสริม (Badges)

Requires Verification Step นี้ต้องมีคนตรวจสอบหลังจาก Completed
รอตรวจสอบ Step X ก่อน Step ก่อนหน้ายังไม่ Verified — กด Start ตอนนี้ไม่ได้
⏳ Awaiting other verifier คุณเป็น operator ของ step นี้ — รอคนอื่นมาเป็น verifier
✓ Sub-steps confirmed ติ๊ก checklist ครบทุกข้อแล้ว — กด Complete ได้

⚠ จุดที่คนพลาดบ่อย

😕 กดปุ่ม Start ไม่ได้
ตรวจ: Step ก่อนหน้า Verified แล้วหรือยัง? ถ้ายัง Completed ก็ยังเริ่มไม่ได้ (ถ้า require verification)
🔍 ไม่มีปุ่ม Verify
คุณคือ operator ของ step นี้ — ต้องให้ user คนอื่น login เข้ามาแทน (GMP dual control)
📝 Sub-steps ยังไม่ติ๊กครบ
ปุ่ม Complete จะใช้ไม่ได้จนกว่าจะติ๊ก checklist ครบทุกข้อ — ใช้ปุ่ม "ทำเครื่องหมายทั้งหมด" ช่วยได้
⚖ Actual ห่างจาก Expected
ระบบไม่ block แต่ควรใส่ Notes อธิบาย เพื่อให้ตอน Verify เข้าใจ
🔄 หน้าไม่ refresh
ระบบ realtime sync ทำงานอัตโนมัติ — ถ้ายังไม่ update ลอง refresh browser หรือเช็คว่า login session ยัง active
🚫 Operator login ผิดคน
ถ้าคน login ที่กด Complete ไม่ใช่คนทำจริง — ตอน Verify จะ block เพราะระบบจำว่า "คน login = operator"
